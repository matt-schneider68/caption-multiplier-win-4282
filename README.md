## About Multiplier

Multiplier is designed for creators, marketers, and teams that need to adapt one piece of source material into multiple publishing formats without reworking the same ideas by hand. It focuses on repurposing long-form content into concise, channel-specific copy that fits common social and newsletter workflows.

The tool is web-based, making it easy to use from a browser while connecting generation to the Anthropic API. It also supports license key unlocking through Gumroad, which can be used as part of the access flow for configured deployments.

- Converts long-form content into platform-specific social posts

- Creates Instagram captions with a different format and tone

- Uses the Anthropic API for AI generation
